# Professional C++

A personal study repository for *Professional C++* by Marc Gregoire.

## Objectives

- Develop a strong understanding of modern C++.
- Practice object-oriented and generic programming.
- Explore the C++ standard library and resource management.
- Write maintainable, testable, and idiomatic C++ programs.
- Document concepts and observations through practical experiments.

## Repository Structure

- `notes/` — Personal notes and concept summaries.
- `exercises/` — Chapter-wise exercise solutions.
- `examples/` — Focused demonstrations of C++ concepts.
- `projects/` — Larger programs combining multiple concepts.

## Environment

- Language: C++
- Build system: CMake
- Compiler: GCC or Clang
